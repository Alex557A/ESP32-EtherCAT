# Добавление USB Keyboard каналов для EtherCAT

## Автоматическое заполнение полей при нажатии клавиши

При нажатии клавиши на физической клавиатуре (подключенной к USB Host порту ESP32-S3) автоматически заполняются следующие поля:

### Автоматически заполняемые поля:

1. **USB key code (HEX)** - автоматически заполняется keycode нажатой клавиши
   - Пример: нажата клавиша `A` → заполняется `0x04`
   - Пример: нажата клавиша `Enter` → заполняется `0x28`

2. **USB кнопка (выпадающий список)** - автоматически выбирается соответствующая запись
   - Пример: при keycode `0x04` автоматически выбирается "A" в списке
   - Позволяет видеть название клавиши

3. **Модификаторы (чекбоксы)** - автоматически отмечаются при нажатии с модификаторами
   - Ctrl, Shift, Alt, Win автоматически отмечаются если были нажаты
   - Пример: `Shift+A` → отмечается чекбокс "Shift"

4. **Index** - автоматически заполняется следующим свободным индексом
   - Учитываются только занятые индексы существующих каналов
   - Пример: если есть каналы с индексами 0, 1, 2 → заполняется `3`
   - Заполняется только для новых каналов (если поле пустое)

5. **PDO byte** - автоматически заполняется следующим свободным byte
   - Для USB каналов учитываются только USB каналы при поиске свободного byte
   - Пример: если есть USB каналы с PDO byte 0, 1, 2 → заполняется `3`
   - Заполняется только если поле пустое

### Заполняется вручную:

1. **Name (Имя)** - обязательное поле, заполняется вручную
   - Пример: "Button_A", "Enter_Key", "Shift_A"

## Пошаговая инструкция добавления USB Keyboard канала

### Способ 1: Использование физической клавиатуры (рекомендуется)

1. **Подключите физическую клавиатуру к USB Host порту ESP32-S3:**
   - D- → GPIO 19
   - D+ → GPIO 20
   - GND → GND
   - 5V → внешний источник питания (минимум 1A)

2. **Откройте веб-интерфейс** и перейдите в раздел "I/O Channels"

3. **Выберите категорию:** "USB Keyboard" (или "USB_KEY")

4. **Нажмите клавишу на физической клавиатуре:**
   - Автоматически заполнятся:
     - USB key code (HEX) - keycode клавиши
     - USB кнопка - название клавиши в списке
     - Модификаторы - если были нажаты
     - Index - следующий свободный индекс
     - PDO byte - следующий свободный byte

5. **Заполните вручную:**
   - **Name** - имя канала (например, "Button_A")

6. **Нажмите "Apply"** для сохранения канала

### Способ 2: Ручной ввод

1. **Выберите категорию:** "USB Keyboard"

2. **Выберите кнопку из выпадающего списка** или введите HEX код вручную в поле "USB key code (HEX)"

3. **Отметьте модификаторы** (если нужны): Ctrl, Shift, Alt, Win

4. **Заполните вручную:**
   - **Index** - индекс канала (или оставьте пустым для автоматического заполнения)
   - **PDO byte** - PDO byte (или оставьте пустым для автоматического заполнения)
   - **Name** - имя канала

5. **Нажмите "Apply"** для сохранения канала

## Обязательные поля для создания USB Keyboard канала

Для создания USB Keyboard канала необходимы следующие поля:

| Поле | Обязательное | Автоматическое заполнение | Описание |
|------|--------------|---------------------------|----------|
| **Category** | Да | Ручной выбор | Должно быть "USB_KEY" или "USB Keyboard" |
| **USB key code (HEX)** | Да | ✅ При нажатии клавиши | HEX код клавиши (например, 0x04 для A) |
| **Модификаторы** | Нет | ✅ При нажатии клавиши | Битовая маска модификаторов (Ctrl, Shift, Alt, Win) |
| **Index** | Да | ✅ При нажатии клавиши | Индекс канала (0-31), автоматически следующий свободный |
| **PDO byte** | Да | ✅ При нажатии клавиши | PDO byte для EtherCAT (0-255), автоматически следующий свободный |
| **PDO bit** | Нет | Автоматически 0 | Для USB каналов не используется (всегда 0) |
| **Name** | Да | ❌ Ручной ввод | Имя канала для идентификации |

## Минимальные данные для создания канала

**Минимально необходимо:**
1. Выбрать категорию "USB Keyboard"
2. Нажать клавишу на физической клавиатуре (заполнит keycode, модификаторы, Index, PDO byte)
3. Заполнить вручную поле **Name**
4. Нажать "Apply"

**Все остальные поля заполняются автоматически!**

## Примеры использования

### Пример 1: Простая клавиша A

1. Выбрать категорию "USB Keyboard"
2. Нажать клавишу `A` на физической клавиатуре
3. Заполнить Name: "Button_A"
4. Нажать "Apply"

**Результат:**
- USB key code: `0x04` (автоматически)
- Index: `0` (автоматически, если это первый канал)
- PDO byte: `0` (автоматически, если это первый канал)
- Name: "Button_A" (вручную)

### Пример 2: Клавиша с модификатором (Shift+A)

1. Выбрать категорию "USB Keyboard"
2. Нажать `Shift+A` на физической клавиатуре
3. Заполнить Name: "Shift_A"
4. Нажать "Apply"

**Результат:**
- USB key code: `0x04` (автоматически)
- Модификаторы: `Shift` отмечен (автоматически)
- Index: `1` (автоматически)
- PDO byte: `1` (автоматически)
- Name: "Shift_A" (вручную)

### Пример 3: Несколько каналов подряд

1. Выбрать категорию "USB Keyboard"
2. Нажать `A` → заполнить Name: "Button_A" → Apply
3. Нажать `B` → заполнить Name: "Button_B" → Apply
4. Нажать `C` → заполнить Name: "Button_C" → Apply

**Результат:**
- Канал 0: keycode=0x04, Index=0, PDO byte=0, Name="Button_A"
- Канал 1: keycode=0x05, Index=1, PDO byte=1, Name="Button_B"
- Канал 2: keycode=0x06, Index=2, PDO byte=2, Name="Button_C"

## Важные замечания

1. **USB Host и USB Device не могут работать одновременно:**
   - Для использования физической клавиатуры (USB Host) нужно отключить USB Device режим
   - USB Device режим используется для отправки клавиш с ESP32 на ПК
   - USB Host режим используется для чтения клавиш с физической клавиатуры

2. **Автоматическое заполнение работает только для новых каналов:**
   - Если Index уже заполнен (редактирование существующего канала), Index не меняется
   - Если PDO byte уже заполнен, PDO byte не меняется

3. **PDO byte для USB каналов:**
   - USB каналы используют целый byte (не используют bit)
   - Каждый USB канал занимает один PDO byte

4. **Валидация:**
   - USB key code должен быть валидным (не 0, если канал включен)
   - Модификаторы должны быть в диапазоне 0-15 (4 бита)

## Технические детали

- **USB Host порт:** D- = GPIO 19, D+ = GPIO 20
- **USB Device порт:** используется для отправки клавиш (TinyUSB)
- **Формат данных:** JSON-RPC через Telnet
- **Веб-интерфейс:** автоматически получает данные о нажатых клавишах через WebSocket
