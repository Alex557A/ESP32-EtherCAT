## [0.1.0-alpha] — 2026-10-21

Первая публичная предварительная редакция. **На реальном оборудовании не
испытывалась:** сборка проходит успешно, обмен с ведущим не подтверждён.

### Добавлено

- **Эмуляция ESC** (`src/ethercat_esc.*`): регистры `0x0000…0x0FFF`, образ SII и
  интерфейс EEPROM `0x0500`, 8 FMMU, 4 SyncManager, статусы DL/AL, счётчики,
  проверка настроек SM, идентификация (Vendor ID, Product Code, Revision, Serial).
- **Обработка кадров** (`src/ethercat_frame.*`): датаграммы APRD/APWR/FPRD/FPWR/
  BRD/BWR/LRD/LWR/LRW, трансляция логических адресов через FMMU, обработчик
  изменений памяти.
- **Словарь объектов и CoE** (`src/ethercat_od.*`): `0x1000`, `0x1008`, `0x1009`,
  `0x100A`, `0x1018`, `0x1600`, `0x1A00`, `0x1C00`, `0x1C12`, `0x1C13`, `0x6000`,
  `0x7010`; SDO upload/download (expedited, обычный и сегментированный обмен),
  Complete Access, сервис SDO Information (OD List / Object Description /
  Entry Description), коды прерываний, применение PDO-маппинга.
- **Distributed Clock** (`src/ethercat_dc.*`): системное время, сдвиг и задержка,
  SYNC0/SYNC1, режимы Free-Run и DC-Synchron, выдача импульсов SYNC0.
- **Стек и конечный автомат** (`src/ethercat_stack.*`, `src/ethercat_fsm.*`):
  переходы INIT → PREOP → SAFEOP → OP, обслуживание почтового ящика, работа с SM.
- **Telnet JSON-RPC** (`src/telnet_server.*`): `get_config`, `set_config`,
  `reset_config` — каналы ввода-вывода, энкодеры, расширитель MCP23S17, сохранение
  во Flash.
- **ESI/EDS-описание** (`esi/ESP32_EtherCAT_Slave_v4.xml`) для TwinCAT/SOEM/IgH.
- **Паспорт изделия** (`docs/ПАСПОРТ_ESP32_EtherCAT_Slave_v4.md`).

### Изменено

- Вендоринг библиотеки USB-Host: `file://`-ссылка на локальный каталог заменена

  не зависит от путей на машине разработчика.
- Учреждены `LICENSE` (MIT), `THIRD_PARTY_NOTICES.md`, `.gitattributes`,
  `CHANGELOG.md`; `docs/China_Devices/` исключён из репозитория.
- Из репозитория убраны девелоперские заметки (23 свитка `.md`).
- Внутренние указания разработчика (`.clinerules`) изъяты и из репозитория, и из
  всей прежней истории; техническое задание и чек-лист реализации в публичную
  редакцию не входят (в прежней истории техническое задание сохранено).

### Известные ограничения

- Обмен с реальным ведущим не проверялся; ESI-файл нигде не регистрировался.
- FMMU: только побайтная трансляция (побитовые отображения не поддерживаются,
  в SII заявлено `bit operation = 0`).
- Запись в SII/EEPROM игнорируется; ответ SDO Information не фрагментируется.
- Точность SYNC0 ограничена программным таймером и планировщиком FreeRTOS.
- Vendor ID `0x00000000` и Product Code `0x00000001` — тестовые, ETG их не выдавала.
