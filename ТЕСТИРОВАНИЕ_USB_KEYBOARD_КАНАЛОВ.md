# Тестирование и улучшения USB Keyboard каналов

**Дата:** 2026-01-27  
**Автор:** Федя  
**Версия:** 1.0

---

## 📋 Резюме улучшений

### ✅ Реализованные улучшения

1. **Парсинг HEX строк для USB key_code и modifiers**
   - Добавлена функция `parse_hex_uint8()` для парсинга HEX строк ("0x04", "04", "4")
   - Добавлена функция `get_uint8_from_json()` для безопасного извлечения uint8 из JSON (поддерживает HEX строки и числа)
   - Обновлена обработка в `set_gpio_channel` и `test_usb_keyboard`

2. **Валидация USB Keyboard параметров**
   - Проверка, что `usb_key_code != 0` для включенных каналов
   - Проверка, что `usb_modifiers <= 0x0F` (4 бита)
   - Возврат понятных ошибок при невалидных параметрах

3. **Улучшенная обработка ошибок**
   - Возврат специфичных ошибок: `invalid_usb_key_code`, `invalid_usb_modifiers`
   - Валидация перед сохранением канала

## 🔧 Технические детали

### Функции парсинга (src/telnet_server.cpp)

```cpp
/**
 * @brief Парсинг HEX строки в uint8_t
 * @param s Строка (может быть "0x04", "04", "4" или число)
 * @param out Результат
 * @return true если успешно
 */
static boolean parse_hex_uint8(const char* s, uint8_t* out);

/**
 * @brief Безопасное извлечение uint8 из JSON параметра (поддерживает HEX строки)
 * @param params JSON объект
 * @param key1 Первый ключ для поиска
 * @param key2 Второй ключ для поиска (опционально)
 * @param default_val Значение по умолчанию
 * @return Извлеченное значение
 */
static uint8_t get_uint8_from_json(JsonObject params, const char* key1, const char* key2, uint8_t default_val);
```

### Обновленная обработка каналов

**До:**
```cpp
ch.usb_key_code = (uint8)(params["usb_key_code"] | params["key_code"] | 0);
ch.usb_modifiers = (uint8)(params["usb_modifiers"] | params["modifiers"] | 0);
```

**После:**
```cpp
// USB key code и modifiers - поддерживаем HEX строки ("0x04") и числа
ch.usb_key_code = get_uint8_from_json(params, "usb_key_code", "key_code", 0);
ch.usb_modifiers = get_uint8_from_json(params, "usb_modifiers", "modifiers", 0);

// Валидация для USB Keyboard каналов
if (ch.type == GPIO_TYPE_USB_KEYBOARD) {
    if (ch.enabled && ch.usb_key_code == 0) {
        (void)telnet_server_send_error(server, "invalid_usb_key_code", req_id);
        return;
    }
    if (ch.usb_modifiers > 0x0F) {
        (void)telnet_server_send_error(server, "invalid_usb_modifiers", req_id);
        return;
    }
}
```

## 🧪 Тестовые сценарии

### Тест 1: Добавление USB Keyboard канала через веб-интерфейс

**Шаги:**
1. Открыть веб-интерфейс (http://localhost:3000)
2. Выбрать активное устройство
3. Перейти на вкладку "IO каналы"
4. Выбрать категорию "USB Keyboard"
5. Выбрать кнопку из списка (например, "A" = 0x04)
6. Установить модификаторы (Ctrl, Shift, Alt, Win)
7. Указать PDO byte и bit
8. Нажать "Сохранить"

**Ожидаемый результат:**
- Канал успешно добавлен
- В Serial Monitor ESP32 видно сообщение: `[GPIO] USB Keyboard канал [X] добавлен: Key=0x04, Modifiers=0x03, PDO byte=Y, bit=Z`
- Канал отображается в списке каналов

**Проверка:**
- Канал виден в списке каналов
- Параметры канала корректны (key_code, modifiers, PDO mapping)
- Канал работает при изменении PDO бита

---

### Тест 2: Добавление канала с HEX строками в JSON

**JSON команда:**
```json
{
  "jsonrpc": "2.0",
  "method": "set_gpio_channel",
  "params": {
    "enabled": true,
    "category": "USB_KEY",
    "usb_key_code": "0x04",
    "usb_modifiers": "0x03",
    "pdo_byte": 0,
    "pdo_bit": 0,
    "name": "Test USB Key"
  },
  "id": 1
}
```

**Ожидаемый результат:**
- Канал успешно добавлен
- `usb_key_code = 0x04` (4)
- `usb_modifiers = 0x03` (3 = Ctrl + Shift)
