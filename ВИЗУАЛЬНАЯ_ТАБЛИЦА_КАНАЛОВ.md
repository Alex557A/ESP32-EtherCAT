# Визуальная таблица каналов

## Описание

Добавлена визуальная таблица для отображения всех I/O каналов с возможностью быстрого редактирования и удаления.

## Расположение

Таблица находится в разделе **"🔧 IO каналы (IN/OUT)"** веб-интерфейса, между JSON отображением каналов и формой редактирования.

## Структура таблицы

Таблица отображает следующие колонки:

| Колонка | Описание |
|---------|----------|
| **Index** | Индекс канала (0-31) |
| **Name** | Имя канала |
| **Category** | Категория (GPIO_ESP, GPIO_EX, USB_KEY) |
| **Enabled** | Статус включения (✓/✗) |
| **USB Key** | USB key code в HEX формате (только для USB_KEY) |
| **Modifiers** | Модификаторы (Ctrl, Shift, Alt, Win) или HEX код |
| **PDO Byte** | PDO byte для EtherCAT |
| **PDO Bit** | PDO bit для EtherCAT |
| **GPIO Pin** | GPIO pin или MCP23S17 port |
| **Actions** | Кнопки Edit и Delete |

## Функциональность

### Автоматическое обновление

Таблица автоматически обновляется при:
- Загрузке каналов (кнопка "Load IO channels")
- Создании нового канала (после нажатия "Apply")
- Редактировании канала (после нажатия "Apply")
- Удалении канала (после подтверждения удаления)

### Кнопка "Edit"

**Действие:** Загружает данные канала в форму редактирования

**Как работает:**
1. Устанавливает выбранный канал в выпадающем списке
2. Загружает данные канала в форму через `loadChannelToForm()`
3. Прокручивает страницу к форме редактирования

**Использование:**
- Нажмите кнопку "Edit" в строке нужного канала
- Форма автоматически заполнится данными канала
- Измените нужные поля
- Нажмите "Apply" для сохранения изменений

### Кнопка "Delete"

**Действие:** Удаляет канал по индексу

**Как работает:**
1. Показывает диалог подтверждения с именем канала
2. Отправляет запрос на удаление через API
3. Обновляет таблицу и выпадающий список после удаления
4. Очищает форму, если удаленный канал был выбран

**Использование:**
- Нажмите кнопку "Delete" в строке нужного канала
- Подтвердите удаление в диалоге
- Канал будет удален, таблица обновится автоматически

## Отображение данных

### Категории

Категории отображаются с цветным фоном:
- **GPIO_ESP** - синий фон (#e0e7ff)
- **GPIO_EX** - синий фон (#e0e7ff)
- **USB_KEY** - синий фон (#e0e7ff)

### Статус включения

- **✓** (зеленый) - канал включен
- **✗** (красный) - канал выключен

### USB Key code

- Отображается в HEX формате: `0x04`, `0x28`, и т.д.
- Для не-USB каналов отображается `-`

### Модификаторы

- Отображаются как текст: `Ctrl+Shift`, `Alt+Win`, и т.д.
- Если модификаторы не распознаны, отображается HEX код: `0x03`
- Для не-USB каналов отображается `-`

### GPIO Pin

- Для **GPIO_ESP**: отображается номер пина: `5`, `12`, и т.д.
- Для **GPIO_EX**: отображается `MCP:0`, `MCP:1`, и т.д.
- Для **USB_KEY**: отображается `-`

## Интеграция с существующим функционалом

### Совместимость

Таблица полностью совместима с существующим функционалом:
- ✅ Выпадающий список каналов продолжает работать
- ✅ Форма редактирования работает как раньше
- ✅ Кнопка "Delete by index" продолжает работать
- ✅ JSON отображение каналов сохраняется

### Преимущества

1. **Быстрый просмотр:** Все каналы видны в одной таблице
2. **Удобное редактирование:** Один клик для загрузки канала в форму
3. **Быстрое удаление:** Удаление прямо из таблицы
4. **Визуальная информация:** Цветовая индикация статуса и категорий

## Технические детали

### Функции

- `renderChannelsTable(channels)` - заполняет таблицу данными каналов
- `editChannel(index)` - загружает канал в форму для редактирования
- `deleteChannelFromTable(index)` - удаляет канал по индексу

### Обновление таблицы

Таблица обновляется через вызов `loadDeviceGPIOChannels()`, который:
1. Загружает данные каналов через API
2. Обновляет JSON отображение
3. Обновляет выпадающий список
4. Вызывает `renderChannelsTable()` для обновления таблицы

### Стилизация

Таблица использует стили, аналогичные таблице PDO Mapping:
- Светлый фон заголовка (#f9fafb)
- Границы между строками (#e5e7eb)
- Hover эффекты на кнопках
- Адаптивная ширина (overflow-x: auto)

## Пример использования

1. **Просмотр каналов:**
   - Откройте раздел "IO каналы"
   - Нажмите "Load IO channels"
   - Просмотрите все каналы в таблице

2. **Редактирование канала:**
   - Найдите нужный канал в таблице
   - Нажмите кнопку "Edit"
   - Измените данные в форме
   - Нажмите "Apply"

3. **Удаление канала:**
   - Найдите нужный канал в таблице
   - Нажмите кнопку "Delete"
   - Подтвердите удаление
   - Канал будет удален, таблица обновится
