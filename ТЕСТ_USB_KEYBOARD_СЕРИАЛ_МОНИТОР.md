# Тест USB Keyboard через Serial Monitor

**Дата:** 2026-01-27  
**Автор:** Федя  
**Версия:** 1.0

---

## 📋 Описание

Простая тестовая функция для проверки работы USB Keyboard на ESP32-S3. Тест выводит подробную информацию в Serial Monitor о каждой попытке нажатия клавиши.

**Цель:** Проверить, что USB Keyboard работает корректно перед тестированием добавления каналов через веб-сервер.

---

## 🚀 Как использовать

### Шаг 1: Откройте Serial Monitor

1. Подключите ESP32-S3 к ПК через USB
2. Откройте Serial Monitor в PlatformIO или Arduino IDE
3. Установите скорость: **115200 baud**
4. Убедитесь, что ESP32 запущен и виден вывод инициализации

### Шаг 2: Запустите тест

**В Serial Monitor введите команду:**
```
usb test
```

**Или:**
```
test usb
```

### Шаг 3: Наблюдайте за выводом

Тест автоматически выполнит следующие действия:

1. Проверит инициализацию USB Keyboard
2. Проверит доступность USB окружения (подключение к ПК)
3. Протестирует 10 различных клавиш:
   - A (без модификаторов)
   - B (без модификаторов)
   - Enter
   - Escape
   - A + Ctrl
   - A + Shift
   - A + Alt
   - A + Win/GUI
   - 1 (цифра)
   - Space

4. Для каждой клавиши:
   - Нажмет клавишу на 200ms
   - Отпустит клавишу
   - Выведет результат (✓ или ✗)

## ✅ Интерпретация результатов

### Успешный тест

**Если все тесты прошли успешно (10/10):**
- USB Keyboard работает корректно
- Можно переходить к тестированию добавления каналов через веб-сервер

**Что проверить на ПК:**
- Откройте текстовый редактор (Notepad, WordPad, etc.)
- Во время теста должны появляться символы: `a`, `b`, `1`, пробелы
- При нажатии Enter должен появляться перевод строки
- При нажатии Escape ничего не должно происходить (или зависеть от приложения)

### Ошибки в тесте

**Если есть ошибки (✗ FAILED):**

1. **"press_key returned false"** или **"release_key returned false"**
   - Проблема с USB Keyboard API
   - Проверьте инициализацию USB
   - Проверьте, что USB окружение доступно

2. **"USB окружение недоступно"**
   - ESP32-S3 не подключен к ПК через USB
   - Или USB не распознается как HID устройство
   - Проверьте USB кабель и драйверы

3. **Клавиши не работают на ПК (но тест проходит)**
   - Проблема с драйверами USB
   - Проблема с USB HID библиотекой
   - Может потребоваться перепрошивка или обновление библиотек

## 🔧 Устранение проблем

### Проблема 1: Ошибка "TX Semaphore is NULL"

**Симптомы:**
```
[E][USBHID.cpp:335] SendReport(): TX Semaphore is NULL. You must call USBHID::begin() before you can send reports
```

**Причина:**
- Не был вызван `begin()` на объекте USBHIDKeyboard после создания

**Решение:**
- ✅ **ИСПРАВЛЕНО** в версии от 2026-01-27
- Добавлен вызов `keyboard->begin()` в функции `usb_keyboard_init()`
- Перепрошейте ESP32 с обновленным кодом

### Проблема 2: USB Keyboard не инициализируется

**Симптомы:**
```
[USB Test] ✗ ERROR: USB Keyboard init failed
```

**Решения:**
1. Проверьте, что используется ESP32-S3 (не ESP32)
2. Перезагрузите ESP32
3. Проверьте, что USB кабель подключен
4. Проверьте Serial Monitor на наличие других ошибок

### Проблема 2: USB окружение недоступно

**Симптомы:**
```
[USB Test] ⚠ WARNING: USB окружение недоступно
```

**Решения:**
1. Убедитесь, что ESP32-S3 подключен к ПК через USB
2. Проверьте, что USB кабель поддерживает передачу данных (не только зарядку)
3. Проверьте драйверы USB на ПК
4. Попробуйте другой USB порт

### Проблема 3: Клавиши не работают на ПК

**Симптомы:**
- Тест проходит успешно (10/10)
- Но на ПК ничего не происходит

**Решения:**
1. Проверьте, что ESP32-S3 распознается как USB HID устройство:
   - Windows: Диспетчер устройств → Устройства HID
   - Linux: `lsusb` или `dmesg | grep -i hid`
   - macOS: Системные настройки → Устройства

2. Проверьте, что фокус находится на приложении, которое может принимать ввод:
   - Откройте текстовый редактор
   - Убедитесь, что окно активно

3. Попробуйте другой USB порт или кабель

## 🎯 Команды Serial Monitor

**Доступные команды для тестирования:**

- `usb test` или `test usb` - запустить тест USB Keyboard
- `test start` - запустить тест EtherCAT (1ms)
- `test start 4ms` - запустить тест EtherCAT (4ms)
- `test stop` - остановить тест EtherCAT
- `test stats` - показать статистику теста EtherCAT

---

**Примечание:** Этот тест предназначен для быстрой проверки работы USB Keyboard перед более сложным тестированием через веб-сервер. Если тест проходит успешно, но клавиши не работают на ПК, проблема может быть в драйверах или настройках ПК.
