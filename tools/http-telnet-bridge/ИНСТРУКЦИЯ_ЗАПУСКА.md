## Шаг 1: Открыть PowerShell в правильной директории

**Вариант 1: Через проводник**
1. Откройте проводник Windows
2. Перейдите в: `C:\Users\alex557\Desktop\EtherCAT\ESP32_EtherCAT_Slave_4\tools\http-telnet-bridge`
3. В адресной строке введите `powershell` и нажмите Enter

**Вариант 2: Через командную строку**
```powershell
cd C:\Users\alex557\Desktop\EtherCAT\ESP32_EtherCAT_Slave_4\tools\http-telnet-bridge
```

## Шаг 2: Установить зависимости

```powershell
npm install
```

Эта команда:
- Прочитает `package.json`
- Установит необходимые библиотеки (express, socket.io и др.)
- Создаст папку `node_modules` с зависимостями

**Ожидаемый вывод:**
```
added 50 packages, and audited 51 packages in 5s
```

## Шаг 3: Запустить веб-сервер

```powershell
npm start
```

**Ожидаемый вывод:**
```
[HTTP] Server running on http://localhost:3000
[Telnet] Connecting to 192.168.20.1:23...
[Telnet] Connected to 192.168.20.1:23
```

## Шаг 4: Открыть веб-интерфейс

Откройте в браузере:
```
http://localhost:3000
```

## Требования

- **Node.js** должен быть установлен на компьютере
- Проверьте установку: `node --version` (должна быть версия 14+)
- Если Node.js не установлен, скачайте с: https://nodejs.org/

## Возможные проблемы

### "npm не распознается как команда"
**Решение:** Node.js не установлен или не добавлен в PATH
- Установите Node.js с https://nodejs.org/
- Перезапустите PowerShell после установки

### "Cannot find module"
**Решение:** Зависимости не установлены
```powershell
npm install
```

### "Port 3000 already in use"
**Решение:** Порт занят другим приложением
- Измените `HTTP_PORT` в `bridge.js` на другой порт (например, 3001)
- Или закройте приложение, использующее порт 3000
