# Улучшения интерфейса USB клавиатуры

**Дата:** 2026-01-27  
**Автор:** Федя

---

## Проблема

В текущей реализации категория USB предлагала список букв, цифр и т.д., но:
- ❌ Не было кнопки Keypad 0 (0x62) - "000" на цифровом блоке
- ❌ Не было других Keypad кнопок (цифровой блок)
- ❌ Нет автоматического определения доступных кнопок
- ❌ Сложная настройка для пользователя

---

## Реализованные улучшения

### 1. ✅ Добавлены все Keypad коды в список

**Добавлены кнопки цифрового блока:**
- Keypad 0 (0x62) - **"000" кнопка**
- Keypad 1-9 (0x59-0x61)
- Keypad . (точка) (0x63)
- Keypad /, *, -, + (0x54-0x57)
- Keypad Enter (0x58)
- Num Lock (0x83)

**Файл:** `tools/http-telnet-bridge/public/index.html` (строки 759-777)

**Структура:**
```html
<optgroup label="--- Keypad (Цифровой блок) ---">
    <option value="0x62">Keypad 0</option>
    <option value="0x59">Keypad 1</option>
    ...
</optgroup>
```

---

### 2. ✅ Функция автоматического сканирования Keypad кнопок

**Новая функция:** `scanUsbKeys()`

**Что делает:**
- Автоматически тестирует все Keypad кнопки (0x54-0x63, 0x83)
- Определяет, какие кнопки доступны на подключенной клавиатуре
- Показывает список доступных и недоступных кнопок
- Помогает пользователю быстро определить, какие кнопки работают

**Использование:**
1. Нажмите кнопку "🔍 Сканировать Keypad кнопки"
2. Система автоматически протестирует все Keypad кнопки
3. Отобразится список доступных кнопок с их HEX кодами

**Файл:** `tools/http-telnet-bridge/public/index.html` (строки ~2070-2130)

---

### 3. ✅ Функция сканирования всех основных кнопок

**Новая функция:** `scanAllUsbKeys()`

**Что делает:**
- Тестирует выборочный набор основных кнопок (буквы, цифры, специальные, keypad)
- Помогает быстро определить, какие типы кнопок доступны
- Показывает результаты в удобном формате

**Использование:**
1. Нажмите кнопку "🔍 Сканировать все кнопки"
2. Система протестирует основные кнопки
3. Отобразится список доступных кнопок

---

### 4. ✅ Улучшенный интерфейс выбора кнопок

**Изменения:**
- Добавлена подсказка о функции сканирования
- Поле ввода HEX кода теперь не только readonly - можно вводить вручную
- Добавлена синхронизация между выпадающим списком и полем ввода
- При вводе HEX кода вручную автоматически обновляется выпадающий список (если код найден)

**Обработчики событий:**
- `ioChUsbKeySelect` (change) → обновляет поле ввода
- `ioChUsbKey` (input) → обновляет выпадающий список (если код найден)

---

### 5. ✅ Быстрый тест Keypad 0

**Добавлена кнопка:** "Тест: Keypad 0" (0x62)

Позволяет быстро протестировать кнопку "000" на цифровом блоке.

## Алгоритм работы

### Автоматическое определение кнопок

1. **Пользователь нажимает "Сканировать Keypad кнопки"**
2. **Система последовательно тестирует каждую Keypad кнопку:**
   - Отправляет команду `test_usb_keyboard` с кодом кнопки
   - Проверяет успешность выполнения
   - Записывает результат (доступна/недоступна)
3. **Отображает результаты:**
   - Список доступных кнопок с HEX кодами
   - Список недоступных кнопок (для информации)

### Упрощенная настройка

**Вариант 1: Через выпадающий список**
- Выбрать категорию "USB Keyboard"
- Выбрать кнопку из списка (включая Keypad кнопки)
- Код автоматически заполняется

**Вариант 2: Через ручной ввод**
- Ввести HEX код напрямую в поле (например: 0x62)
- Система автоматически синхронизирует со списком (если код найден)

**Вариант 3: Через сканирование**
- Нажать "Сканировать Keypad кнопки"
- Система определит доступные кнопки
- Выбрать нужную из списка доступных

## Использование

### Для настройки IO канала с USB клавиатурой:

**Рекомендуемый способ (с физической клавиатурой):**

1. **Подключите физическую клавиатуру к USB Host порту ESP32-S3:**
   - D- → GPIO 19, D+ → GPIO 20, GND → GND, 5V → внешний источник питания

2. **Выберите категорию:** "USB Keyboard"

3. **Нажмите клавишу на физической клавиатуре:**
   - Автоматически заполнятся: USB key code, USB кнопка (выпадающий список), модификаторы, Index, PDO byte

4. **Заполните вручную только поле Name** (имя канала)

5. **Нажмите "Apply"** для сохранения

**Альтернативные способы:**

**Способ 2: Через выпадающий список**
- Выбрать категорию "USB Keyboard"
- Выбрать кнопку из списка (включая Keypad кнопки)
- Код автоматически заполняется
- Заполнить вручную: Index, PDO byte, Name

**Способ 3: Через ручной ввод**
- Ввести HEX код напрямую в поле (например: 0x62)
- Система автоматически синхронизирует со списком (если код найден)
- Заполнить вручную: Index, PDO byte, Name

**Способ 4: Через сканирование**
- Перейти на вкладку "System"
- Нажать "🔍 Сканировать Keypad кнопки"
- Выбрать нужную кнопку из списка доступных
- Заполнить вручную: Index, PDO byte, Name

**См. подробную инструкцию:** `ДОБАВЛЕНИЕ_USB_KEYBOARD_КАНАЛОВ.md`

### Для тестирования кнопок:

1. Перейдите на вкладку "System"
2. Раздел "Тест USB клавиатуры"
3. Используйте:
   - Быстрые кнопки (A, Enter, Escape, Keypad 0)
   - Или введите код вручную
   - Или используйте сканирование

## Технические детали

### USB HID Keypad коды:
- 0x59-0x61: Keypad 1-9
- 0x62: Keypad 0 (кнопка "000")
- 0x63: Keypad . (точка)
- 0x54: Keypad / (слэш)
- 0x55: Keypad * (звездочка)
- 0x56: Keypad - (минус)
- 0x57: Keypad + (плюс)
- 0x58: Keypad Enter
- 0x83: Num Lock

### API endpoints:
- `POST /api/devices/:ip/test/usb-keyboard` - тестирование кнопки
- `POST /api/devices/:ip/validate/usb-keyboard` - валидация всех каналов
