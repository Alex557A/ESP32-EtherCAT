# Инструкция по запуску Web Server

## Быстрый запуск

### Вариант 1: Двойной клик (рекомендуется)

1. Найдите файл **`start_server.bat`** в папке:
   ```
   C:\Users\alex557\Desktop\EtherCAT\ESP32_EtherCAT_Slave_4\tools\http-telnet-bridge\
   ```

2. **Двойной клик** по файлу `start_server.bat`

3. Откроется окно PowerShell/CMD, сервер запустится автоматически

4. Браузер откроется автоматически через 2 секунды на адресе `http://localhost:3000`

### Вариант 2: Ярлык на рабочем столе

1. Правой кнопкой мыши на файл `start_server.bat`
2. Выберите "Создать ярлык"
3. Перетащите ярлык на рабочий стол
4. Двойной клик по ярлыку для запуска

## Первый запуск

При первом запуске нужно установить зависимости:

1. Запустите **`install_dependencies.bat`** (один раз)
2. Дождитесь завершения установки
3. Затем запустите **`start_server.bat`**

## Файлы

- **`start_server.bat`** - Запуск веб-сервера (основной файл)
- **`install_dependencies.bat`** - Установка зависимостей (только первый раз)
- **`bridge.js`** - Основной код сервера
- **`package.json`** - Список зависимостей

## Требования

- **Node.js** должен быть установлен
- Если не установлен: https://nodejs.org/ (скачайте LTS версию)

## Остановка сервера

Нажмите **Ctrl+C** в окне, где запущен сервер

## Настройка IP адреса ESP32

Если ESP32 имеет другой IP адрес, отредактируйте файл `bridge.js`:

```javascript
const TELNET_HOST = '192.168.20.1';  // Измените на IP вашего ESP32
```

## Возможные проблемы

### "Node.js не найден"
**Решение:** Установите Node.js с https://nodejs.org/

### "Port 3000 already in use"
**Решение:** Измените `HTTP_PORT` в `bridge.js` на другой порт (например, 3001)

### "Cannot connect to Telnet"
**Решение:** 
- Проверьте, что ESP32 запущен
- Проверьте IP адрес ESP32 в `bridge.js`
- Убедитесь, что Telnet Server на ESP32 активен
