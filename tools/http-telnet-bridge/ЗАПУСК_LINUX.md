# Запуск сервера в Linux

## Быстрый старт

### 1. Установка Node.js (если не установлен)

```bash
sudo apt update
sudo apt install -y nodejs npm
```

Проверка:
```bash
node --version
npm --version
```

### 2. Переход в директорию

```bash
cd /media/alex/One/EtherCAT/ESP32_EtherCAT_Slave_4/tools/http-telnet-bridge
```

### 3. Установка зависимостей (только первый раз)

```bash
./install_dependencies.sh
```

Или вручную:
```bash
npm install
```

### 4. Создание ярлыков на рабочий стол (опционально)

```bash
./create_desktop_shortcuts.sh
```

Это создаст три ярлыка на рабочем столе:
- **ESP32_Bridge_Start.desktop** - для запуска сервера (обычный режим)
- **ESP32_Bridge_Restart.desktop** - для перезапуска сервера
- **ESP32_Bridge_Dev.desktop** - для запуска в режиме разработки (автоперезагрузка)

### 5. Запуск сервера

**Вариант 1: Через ярлык на рабочем столе**
- Двойной клик по **ESP32_Bridge_Start.desktop**

**Вариант 2: Через скрипт**
```bash
./start_server.sh
```

**Вариант 3: Вручную**
```bash
npm start
```

**Вариант 4: Режим разработки (с автоперезагрузкой)**
```bash
./start_dev.sh
```
Или через ярлык: **ESP32_Bridge_Dev.desktop**

В режиме разработки сервер автоматически перезагружается при изменении файлов `bridge.js` или файлов в папке `public/`.

### 6. Открыть в браузере

```
http://localhost:3000
```

## Перезапуск сервера

**Вариант 1: Через ярлык**
- Двойной клик по **ESP32_Bridge_Restart.desktop**

**Вариант 2: Через скрипт**
```bash
./restart_server.sh
```

Скрипт автоматически:
- Найдет и остановит процесс на порту 3000
- Запустит сервер заново

## Остановка

Нажмите **Ctrl+C** в терминале.

## Настройка IP ESP32

Если ESP32 имеет другой IP, установите переменную окружения:
```bash
TELNET_HOST=192.168.1.100 ./start_server.sh
```

Или измените в `bridge.js`:
```javascript
const DEFAULT_TELNET_HOST = process.env.TELNET_HOST || '192.168.20.1';
```

## Изменение порта HTTP

```bash
HTTP_PORT=3001 ./start_server.sh
```

## Режим разработки (автоперезагрузка)

Для разработки используйте режим с автоперезагрузкой:

```bash
./start_dev.sh
```

Или через ярлык: **ESP32_Bridge_Dev.desktop**

**Особенности режима разработки:**
- Автоматическая перезагрузка при изменении `bridge.js`
- Автоматическая перезагрузка при изменении файлов в `public/`
- Отслеживание изменений в реальном времени
- Не нужно вручную перезапускать сервер после каждого изменения

**Когда использовать:**
- При разработке и изменении кода сервера
- При изменении веб-интерфейса (HTML/CSS/JS в `public/`)
- Для быстрой итерации при отладке

**Когда НЕ использовать:**
- В продакшене (используйте `start_server.sh`)
- Если нужна стабильная работа без перезагрузок

## Настройка сети для EtherCAT + Telnet

Для работы сервера необходимо настроить сетевой интерфейс для доступа к ESP32.

### Быстрая настройка (временная, до перезагрузки)

```bash
sudo ./setup_network.sh
```

Этот скрипт:
- Настроит интерфейс `enp3s0` с IP `192.168.20.100`
- Добавит маршрут к сети `192.168.20.0/24`
- Проверит доступность ESP32

### Постоянная настройка (сохраняется после перезагрузки)

```bash
sudo ./setup_network_permanent.sh
```

Создаст постоянную конфигурацию в `/etc/netplan/` или `/etc/network/interfaces.d/`

### Проверка сетевой конфигурации

```bash
./check_network.sh
```

Проверит:
- Настройку интерфейса
- Маршруты к сети ESP32
- Доступность ESP32
- Работу Telnet порта
- Работу HTTP сервера

### Ручная настройка

Если нужно настроить вручную:

```bash
# Настройка IP адреса
sudo ip addr add 192.168.20.100/24 dev enp3s0
sudo ip link set enp3s0 up

# Проверка
ping -c 2 192.168.20.1
```

**Важно:** 
- Интерфейс `enp3s0` используется для EtherCAT (MACRAW) и Telnet (TCP/IP) одновременно
- Оба протокола работают параллельно на одном физическом интерфейсе
- EtherCAT использует Socket 0 (MACRAW mode)
- Telnet использует Socket 1 (TCP mode)

## Доступные скрипты

- **`start_server.sh`** - Запуск сервера (обычный режим)
- **`start_dev.sh`** - Запуск сервера в режиме разработки (автоперезагрузка)
- **`restart_server.sh`** - Перезапуск сервера (останавливает старый процесс и запускает новый)
- **`setup_network.sh`** - Настройка сети (временная)
- **`setup_network_permanent.sh`** - Настройка сети (постоянная)
- **`check_network.sh`** - Проверка сетевой конфигурации
- **`install_dependencies.sh`** - Установка зависимостей Node.js
- **`create_desktop_shortcuts.sh`** - Создание ярлыков на рабочий стол
