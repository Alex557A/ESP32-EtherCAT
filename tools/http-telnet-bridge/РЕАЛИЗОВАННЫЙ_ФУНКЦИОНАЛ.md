# Реализованный функционал HTTP-to-Telnet Bridge

**Дата:** 2026-01-19  
**Версия:** 1.0  
**Автор:** Федя  
**Платформа:** Windows/Linux/macOS

---

## 1. Архитектура

### 1.1 Компоненты

1. **Node.js HTTP Server** (`bridge.js`)
   - Express.js для HTTP API
   - Socket.IO для WebSocket соединений
   - Telnet клиент (net.Socket) для связи с ESP32

2. **Веб-интерфейс** (`public/index.html`)
   - Real-time обновление через Socket.IO
   - Отображение статистики и конфигурации
   - Управление тестами

3. **Telnet Server на ESP32** (`src/telnet_server.cpp`)
   - Обработка команд через Socket 1 (TCP, port 23)
   - JSON-RPC протокол
   - Параллельная работа с EtherCAT (Socket 0)

## 2. Реализованные API Endpoints

### 2.1 Статистика и мониторинг

| Endpoint | Метод | Описание | Telnet команда |
|----------|-------|----------|----------------|
| `/api/stats` | GET | Получить текущую статистику | `test stats` |
| `/api/test/start` | POST | Запустить тест | `test start [1ms\|4ms]` |
| `/api/test/stop` | POST | Остановить тест | `test stop` |
| `/api/test/stats` | POST | Обновить статистику теста | `test stats` |

### 2.2 Системная информация

| Endpoint | Метод | Описание | Telnet команда |
|----------|-------|----------|----------------|
| `/api/system/info` | GET | Получить системную информацию | `get_system_info` |

**Возвращаемые данные:**
- Chip Model (ESP32-S3)
- Chip Revision
- CPU Frequency (MHz)
- Free Heap (bytes)
- Uptime (ms)

### 2.3 Сетевая конфигурация

| Endpoint | Метод | Описание | Telnet команда |
|----------|-------|----------|----------------|
| `/api/network/config` | GET | Получить сетевую конфигурацию | `get_network_config` |

**Возвращаемые данные:**
- IP Address
- Subnet Mask
- Gateway
- Next Device IP

### 2.4 Конфигурация устройства (базовая)

| Endpoint | Метод | Описание | Telnet команда |
|----------|-------|----------|----------------|
| `/api/config` | GET | Получить полную конфигурацию | `get_config` |
| `/api/gpio/channels` | GET | Получить список GPIO каналов | `get_gpio_channels` |
| `/api/encoders` | GET | Получить список энкодеров | `get_encoders` |

**Статус:** Команды реализованы, но возвращают пустые данные (требуется модуль config_storage)

## 3. Веб-интерфейс

### 3.1 Реализованные секции

1. **EtherCAT Stack Statistics**
   - State (INIT, PRE_OP, SAFE_OP, OPERATIONAL)
   - RX Frames
   - TX Frames
   - Dropped Frames

2. **Test Statistics**
   - Frames Sent
   - Frames Received
   - Frames Dropped
   - Drop Rate (%)

3. **Latency Statistics**
   - Min Latency (μs)
   - Max Latency (μs)
   - Average Latency (μs)
   - Samples Count

4. **Telnet Server**
   - Status (Running/Stopped)
   - Connections Count
   - Commands Processed

5. **System Information**
   - Chip Model
   - Chip Revision
   - CPU Frequency
   - Free Heap
   - Uptime

6. **Network Configuration**
   - IP Address
   - Subnet Mask
   - Gateway

### 3.2 Управление

- **Test Controls:**
  - Start Test (1ms)
  - Start Test (4ms)
  - Stop Test
  - Refresh Stats

- **System Info:**
  - Refresh System Info

- **Network Config:**
  - Refresh Network Config

## 4. Real-time обновления

### 4.1 WebSocket события

- `stats_update` - обновление статистики
- `telnet_status` - статус подключения Telnet
- `telnet_result` - результаты команд (system, network, config, channels, encoders)
- `telnet_response` - сырые ответы от Telnet (для отладки)

### 4.2 Автоматическое обновление

- Статистика обновляется каждые 2 секунды
- Системная информация загружается при старте
- Сетевая конфигурация загружается при старте

## 5. Telnet команды на ESP32

### 5.1 Реализованные команды

1. **`test stats`** - Получить статистику теста и EtherCAT
2. **`test start [1ms|4ms]`** - Запустить тест с указанным периодом
3. **`test stop`** - Остановить тест
4. **`get_system_info`** - Получить системную информацию
5. **`get_network_config`** - Получить сетевую конфигурацию
6. **`get_config`** - Получить полную конфигурацию (заглушка)
7. **`get_gpio_channels`** - Получить список GPIO каналов (заглушка)
8. **`get_encoders`** - Получить список энкодеров (заглушка)

### 5.2 Формат ответов

Все команды возвращают JSON-RPC ответы:

```json
{
  "id": 1,
  "success": true,
  "result": {
    // Данные ответа
  }
}
```

## 6. Установка и запуск

### 6.1 Требования

- Node.js (LTS версия, рекомендуется v20.x)
- npm (входит в Node.js)

### 6.2 Установка

1. Открыть терминал в папке `tools/http-telnet-bridge`
2. Установить зависимости:
   ```bash
   npm install
   ```

### 6.3 Запуск

**Windows:**
- Двойной клик на `start_server.bat`
- Или запустить ярлык на рабочем столе

**Linux/macOS:**
```bash
npm start
```

### 6.4 Доступ

- Веб-интерфейс: http://localhost:3000
- API: http://localhost:3000/api/...

## 7. Конфигурация

### 7.1 Настройки ESP32

По умолчанию:
- **IP Address:** 192.168.20.1
- **Telnet Port:** 23

Для изменения IP адреса ESP32:
1. Изменить Station Address в коде
2. Или использовать команду `set_network_config` (TODO)

### 7.2 Настройки Bridge

В `bridge.js`:
```javascript
const TELNET_HOST = '192.168.20.1';  // IP ESP32
const TELNET_PORT = 23;              // Telnet порт
const HTTP_PORT = 3000;               // HTTP порт
```

## 9. Примечания

### 9.1 Платформо-зависимые особенности

**Windows:**
- Используется `start_server.bat` для запуска
- Кодировка UTF-8 настроена автоматически (`chcp 65001`)
- Ярлык на рабочем столе создается автоматически

**Linux/macOS:**
- Используется `npm start` для запуска
- Кодировка UTF-8 по умолчанию
- Ярлык не создается (можно создать вручную)

### 9.2 Отладка

- Все команды и ответы логируются в консоль Node.js
- Веб-интерфейс показывает статус подключения Telnet
- В консоли браузера (F12) видны все WebSocket события
